PROJECT / 01
DEVICE CONTROL

Qt + STM32
모터 제어 시스템

Qt 화면에서 모터의 ON/OFF와 속도를 조절하고, UART로 STM32의 상태를 확인하는 장비 제어 프로젝트입니다.

C / C++Qt WidgetsSTM32UART / PWM
코드와 문서 ↗시연 영상 ↗
구현 내용 살펴보기

제어 흐름 — Qt SerialPort에서 명령을 전송하고 STM32가 PWM 출력으로 모터 속도를 제어합니다.

통신 — 115200 baud UART, 줄바꿈 기반 ON / OFF / SPEED 명령과 모터 상태 피드백을 사용합니다.

하드웨어 — NUCLEO-F411RE, EZ Motor R300 모듈과 ST-LINK Virtual COM을 연결합니다.
