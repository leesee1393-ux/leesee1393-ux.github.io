# Sehyung · Embedded Developer Portfolio

C/C++, MCU, Qt 기반 장비 제어 프로젝트를 소개하는 반응형 정적 포트폴리오입니다.

## 파일 수정
- `index.html`: 소개 문구, 프로젝트, 이미지, 스타일을 수정합니다.
- 별도 설치나 빌드가 필요 없습니다. 로컬에서는 `python3 -m http.server 8000`으로 확인할 수 있습니다.
- 팀 프로젝트의 개인 기여도는 본인 역할을 확인한 후 추가하세요.
- 프로젝트 이미지와 영상은 원본 GitHub 저장소와 첨부 자료를 참조합니다.

## GitHub Pages
Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택하세요.
`main`에 변경을 올리면 포함된 워크플로가 배포합니다. Actions 탭에서 수동 실행도 가능합니다.

현재 저장소 이름은 `sehyung.github.io`이고 계정 이름은 `leesee1393-ux`이므로 프로젝트 사이트 주소는 다음과 같습니다.
https://leesee1393-ux.github.io/
